# حين يغيب الأب… يبقى أثره: فيديو موشن إنفوجرافيك

فيديو عمودي بمقاس 9:16 ودقة 1080×1920 بمعدل 30 إطارًا في الثانية، لريلز إنستغرام وX.
الرسوم كلها SVG متجهية، وتُبنى باستخدام Line Drawing وMorphing وKinetic Typography، وتتحرك متزامنة مع كل كلمة.

## الملفات

| الملف | الوظيفة |
|---|---|
| `script.txt` | نص التسجيل مقسّمًا إلى عبارات، ولكل عبارة `[مشهد]`، والكلمة المؤثرة توضع بين `*نجمتين*` |
| `timeline.js` | توقيت كل كلمة. يُولَّد تلقائيًا، فلا تحرّره يدويًا |
| `index.html` | محرّك الحركة وجميع المشاهد. افتحه في المتصفح للمعاينة مع شريط تشغيل |
| `config.js` | حساب إنستغرام، وحساب X، ومسار الشعار، والموسيقى |
| `assets/` | ضع هنا `voice.mp3` (التسجيل الأصلي) و`logo.png`. أما `music.m4a` فموسيقى هادئة مولَّدة خصيصًا للفيديو |
| `scripts/render.js` | يصدّر MP4 إطارًا بإطار، ثم يدمج الصوت الأصلي معه |

## ربط التسجيل الصوتي الأصلي

```bash
# 1) توقيت الكلمات من التسجيل
pip install faster-whisper
python3 scripts/transcribe.py assets/voice.mp3 > words.json
# 2) مطابقة التوقيت مع النص، فتصبح مدة الفيديو هي مدة التسجيل
python3 scripts/build_timeline.py --audio assets/voice.mp3 --words words.json
#    أضف --match-audio لمنع أي إطالة: عندها تظهر شاشة الختام فوق آخر ثوانٍ من التسجيل
# 3) التصدير
node scripts/render.js            # ← out/father-reel.mp4
node scripts/render.js --no-music # بالصوت الأصلي فقط
```

يُدمج الصوت الأصلي بمستوى 1.0 كما هو، دون أي فلاتر أو تغيير في السرعة أو النبرة. أما الموسيقى فمستواها 0.10 (يمكن تعديله عبر `--music-volume`).

## المناطق الآمنة للريلز
- يبدأ المحتوى المرئي من y≈330، والنص في المنطقة من y=1185 إلى 1565.
- يُترك هامش 140px على اليمين لأزرار التفاعل.
- يظهر الشعار الصغير في الأعلى عند y=228.
