# من الصَّوت إلى الصَّدى: النسخة الرنّانة

فيديو تشويقي مستوحى من فكرة الفيديو المرجعي: من الموجة الصوتية إلى العنوان، ثم بناء متتابع للتصميم، ثم «تَرَقَّبُوا». المقاس 9:16 بدقة 1080×1920، والمدة 25 ثانية.

**تسلسل المشاهد:**
1. موجة صوتية نيون داخل دائرة تتحوّل إلى «من الصَّوت» بخط رقعة ذهبي، ثم تظهر «إلى الصَّدى» مع صدى بصري وحلقات تتسع.
2. يرتفع العنوان إلى الأعلى، ويظهر شعار المدرسة والحسابات، ثم شريط طيف صوتي ينبض مع الإيقاع، ثم «شراكةٌ تتجاوز المدى» مع دائرتين تلتقيان.
3. ثلاث بطاقات زجاجية تظهر بالتتابع، ولكل بطاقة أيقونة متوهجة ورقم، ويربط بينها خط مضيء:
   - مبادراتٌ تُلهم…
   - وحواراتٌ تُثري…
   - وأثرٌ يمتد
4. تظهر «تَرَقَّبُوا» بضربة موسيقية، ثم صمت قصير، ثم تبقى «تَرَقَّبُوا» وحدها في الوسط وتحتها «قريبًا»، والشعار تحتهما تخرج منه حلقات صدى رنّانة.
5. بطاقة الختام: اسم المدرسة والأسماء الثلاثة.

**ما يبقى ظاهرًا طوال الفيديو:** الشعار داخل دائرة بيضاء، وأيقونتا Instagram وX مع الحساب `edugovnbt2264`.

python3 scripts/soundtrack.py && node scripts/render.js
