# رحلة الموجة: من الصَّوت إلى الصَّدى (3D)

فيديو تشويقي ثلاثي الأبعاد، مبني بمكتبة Three.js. المقاس 9:16 بدقة 1080×1920، والمدة 25 ثانية. الفيديو رحلة كاميرا واحدة متصلة تتبع موجة صوتية من لحظة ولادتها حتى يصبح صداها كل شيء.

| الزمن | المشهد |
|---|---|
| 0–5 ث | نواة ضوء فوق سطح موجي ثلاثي الأبعاد تتموّج منه نقاط الضوء. تخرج «الصَّوت» بحروف ذهبية مجسّمة، ثم تتحوّل إلى حلقات، ثم إلى «الصَّدى» مع نسخ تتلاشى خلفها كالصدى، ثم العنوان كاملًا |
| 5–10 ث | الكاميرا تعبر نفقًا من حلقات الصدى. تتجمّع ثلاث كرات زجاجية، وتتصل بخيوط ضوء، ثم تتشكّل حولها كرة شبكية ← «شراكةٌ تتجاوز المدى» |
| 10–15 ث | ثلاث منصّات عائمة: مصباح زجاجي يتجمّع من شظايا ثم يضيء، وفقاعتا حوار يتنقل بينهما ضوء، وقطرة تسقط في ماء ذهبي فتنتشر منها الدوائر. بعدها ترتفع الكاميرا ويُرسم خيط ضوء يربط المنصّات |
| 15–20 ث | ظلام، ثم ومضة، ثم «تَرَقَّبُوا» مجسّمة في المنتصف. تنفصل المجسّمات عن منصّاتها وتدور حول الكلمة مع الكرات الثلاث، وتخرج حلقات صدى، ثم تظهر «قريبًا» |
| 20–25 ث | الشعار في الأعلى، وتحته الأسماء بالتتابع |

ما يبقى ظاهرًا طوال الفيديو: شعار المدرسة داخل دائرة بيضاء، وأيقونتا Instagram وX مع الحساب `edugovnbt2264`.

## التشغيل والتصدير

صفحة الفيديو تحتاج خادمًا محليًا، لأن وحدات ES لا تعمل حين تُفتح الصفحة كملف مباشرة:

```bash
python3 -m http.server 8790   # ثم افتح http://127.0.0.1:8790/
python3 scripts/soundtrack.py # يولّد الموسيقى والمؤثرات ويضع التعليق الصوتي
node scripts/render.js        # يصدّر out/teaser-3d.mp4
```
