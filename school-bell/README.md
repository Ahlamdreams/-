# 🚣 مِجْداف — الجرس والشاشة الذكية للمدرسة

> نُجدّف معاً بإيقاعٍ واحد. كما يحرّك المجداف القارب بإيقاعٍ منتظم، يُنظّم «مِجْداف» اليوم الدراسي: الجرس، والحصص، والمناوبة، والاحتياط، والأذكار — في شاشة واحدة.

برنامج يعمل **على جهاز واحد بدون إنترنت وبدون خادم**. كل البيانات (الإعدادات، الأصوات، ملفات PDF والفيديو) تبقى على نفس الجهاز.

## التشغيل
1. انسخ مجلد `school-bell` كاملاً إلى الجهاز (مثلاً `C:\school-bell`).
2. شغّل الملف **`start-bell.bat`** (دبل كليك). يفتح البرنامج بملء الشاشة ويعمل الصوت تلقائياً.
   - البيانات تُحفظ داخل مجلد `browser-data` بجانب البرنامج، فلو نسخت المجلد كله لجهاز آخر تنتقل البيانات معه.
   - استخدم دائماً نفس طريقة التشغيل (الملف bat) حتى تظهر نفس البيانات.
3. لتشغيله تلقائياً عند تشغيل الجهاز: اضغط `Win + R` واكتب `shell:startup` ثم ضع فيه **اختصاراً** لملف `start-bell.bat`.

> يمكن أيضاً فتح `index.html` مباشرة في Chrome أو Edge، لكن سيطلب ضغطة لتفعيل الصوت، وتكون بياناته منفصلة عن بيانات ملف bat.

## الشاشة الرئيسية
- الأعلى: شعار المدرسة واسمها، الساعة، التاريخ الهجري والميلادي، ثم شريط "الحصة الآن" مع العداد التنازلي.
- الوسط: مشاهد تتبدل بحركات انتقال متنوعة: ترحيب، **الحصة الآن (كل صف ← المادة ← المعلم، مع الاحتياط: الغائب ← البديل)**، المناوبين في الفسحة، توقيت اليوم، حصص الاحتياط، أذكار، صور وفيديو وجدول PDF. عند بداية كل حصة يقفز تلقائياً لمشهد "الحصة الآن".
- الشريط المتحرك أسفل أو أعلى الشاشة.
- **الثيمات:** رؤية عُمان 2040 (داكن/فاتح)، ألوان علم عُمان، ليلي، رمال، فاتح — أو ألوان مخصصة.

## الاستخدام
- كل الإعدادات خلف زر ⚙️ في زاوية الشاشة.
- حرّك الفأرة لتظهر أزرار التحكم على اليسار: ⚙️ الإعدادات، ⛶ ملء الشاشة، 🔔 جرس يدوي، 🔊 إيقاف/تشغيل الجرس التلقائي، ⏹ إيقاف الصوت، ⏭ الشريحة التالية، 📢 إعلان فوري.
- اختصارات: `S` الإعدادات، `F` ملء الشاشة، `B` جرس يدوي، `M` إيقاف الجرس التلقائي، `Esc` إيقاف الصوت، `A` قائمة الإعلانات الفورية، `1`-`9` تشغيل إعلان فوري مباشرة.

## المزايا
| القسم | ماذا يفعل |
|---|---|
| **التواقيت (جديد)** | بطاقات للتواقيت (شتوي، صيفي، صفرية، رمضان، اختبارات، الخميس) من قوالب جاهزة، وتوقيت يُطبَّق تلقائياً بين تاريخين. **📷 قراءة التوقيت من صورة** بدون إنترنت، و**منتقي وقت سهل** بدون كتابة، و**ما يظهر في الشاشة** لكل فترة. |
| **مدرسة بفترتين** | من ⚙️ ← عام ← "تفعيل نظام الفترتين": لكل فترة (صباحية/مسائية) توقيتها وجدول معلميها ومناوبتها واحتياطها وغيابها. الجرس يرن للفترتين، والشاشة تنتقل تلقائياً للفترة الحالية. |
| **الجداول والتوقيت** | جداول متعددة (أساسي / خميس / رمضان / اختبارات) لكل منها أيامه. لكل فترة: النوع (طابور، صفرية، الأولى…الثامنة، فسحة، نشاط، ريادة، صلاة، انصراف، مخصص)، الوقت من/إلى، جرس البداية والنهاية، والإعلان الصوتي. يوجد مولّد تلقائي للجدول. |
| **الأصوات** | 7 أجراس مدمجة لا تحتاج ملفات + رفع أصوات (MP3/WAV) + تسجيل بالميكروفون. النطق الآلي: "بدأت الآن الحصة الأولى" / "انتهت الآن…"، ويُدمج الإعلانان عند تتابع الحصص. |
| **تنبيهات وإعلانات** | منتصف الحصة ("اللهم صلِّ على محمد")، قبل نهاية الحصة أو الفسحة بـ X دقائق، أو وقت ثابت يومياً (مثل صلاة الظهر). عبارات جاهزة تُضاف بضغطة. **إعلانات فورية** بزر 📢 أو الأرقام 1-9. |
| **أذكار وتحفيز** | تظهر تلقائياً بدون إعداد: بطاقة متبدلة وشرائح كبيرة (سبحان الله، أستغفر الله… / الانضباط، الانتظام، النظافة…). اختيارياً تُنطق بصوت خافت وسريع في الطابور والفسحة وبين الحصص فقط، ويمكن إضافة تسجيلات صوتية لها. |
| **العرض والشريط** | شرائح متحركة: جدول الحصص PDF (كل صفحة شريحة)، صور، فيديو **مكتوم الصوت** افتراضياً، روابط، نصوص، وشرائح تلقائية (توقيت اليوم، المناوبة، الاحتياط). شريط أخبار متحرك أسفل الشاشة. |
| **جدول المعلمين** | من يدرّس كل صف في كل حصة: استيراد Excel (الصفوف × الحصص، ورقة لكل يوم) أو جدول المعلمين (المعلم × الحصص) أو إدخال يدوي. |
| **المناوبة** | من ملف Excel/CSV أو رابط Google Sheets أو إدخال يدوي. يعرض المناوب **الآن** حسب اليوم + الحصة/الفسحة + رقم الأسبوع في الدورة. |
| **الاحتياط** | يعرض حصص الاحتياط لتاريخ اليوم ويبرز حصة الوقت الحالي. |
| **عام** | الشعار، الألوان، أيام الدوام، الإجازات، دورة الأسابيع، تصحيح فرق الساعة، التاريخ الهجري والميلادي. |
| **نسخ احتياطي** | ملف واحد يحفظ كل شيء لنقله أو استرجاعه. |

## ملاحظات
- **الصوت العربي للنطق الآلي:** في ويندوز 10/11 أضف اللغة العربية مع ميزة "تحويل النص إلى كلام" (الإعدادات ← الوقت واللغة ← اللغة). إن لم تتوفر، ارفع تسجيلات صوتية واخترها بدل النطق الآلي.
- **روابط Google Sheets:** شارك الملف "لأي شخص لديه الرابط". يتم التحديث تلقائياً كل عدة دقائق، وتبقى آخر نسخة ظاهرة إن انقطع الإنترنت.
- **اترك الجهاز يعمل:** عطّل وضع السكون من إعدادات الطاقة في ويندوز حتى لا يتوقف الجرس.
- المكتبات المضمنة في `lib/`: ‏SheetJS (قراءة Excel) و PDF.js (عرض PDF) — كلاهما برخصة Apache 2.0.

## الروابط
يقبل البرنامج أي رابط في المناوبة والاحتياط والغياب وجدول المعلمين، ويحاول قراءته تلقائياً:
Google Sheets، Google Docs، ملف في Google Drive، ملف PDF أو Excel أو CSV، رابط Apps Script يُرجع JSON، أو صفحة ويب فيها جدول.
زر **🔍 فحص الرابط** يوضح ما قرأه البرنامج قبل اعتماده.
المواقع التي تمنع قراءة بياناتها (مثل Canva غالباً) فعّل لها **"عرض الرابط كمشهد في الشاشة"** فتظهر كما هي.

### رابط Apps Script (الاحتياط أو الغياب من شيت)
افتح الشيت ← الإضافات ← Apps Script، والصق هذا الكود، ثم: نشر ← نشر جديد ← تطبيق ويب ← "الوصول: أي شخص"، وانسخ الرابط إلى البرنامج:

```javascript
function doGet(e) {
  var name = e.parameter.sheet;                       // اختياري: ?sheet=الاحتياط
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sh = name ? ss.getSheetByName(name) : ss.getSheets()[0];
  var values = sh.getDataRange().getDisplayValues();  // الصف الأول = العناوين
  return ContentService.createTextOutput(JSON.stringify(values))
    .setMimeType(ContentService.MimeType.JSON);
}
```
