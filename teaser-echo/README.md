# من الصَّوت إلى الصَّدى: فيديو تشويقي

فيديو موشن إنفوجرافيك تشويقي لمدرسة أم مالك الأنصارية للبنات. مقاسه عمودي 9:16 بدقة 1080×1920، ومدته 25 ثانية، بمعدل 30 إطارًا في الثانية.

جميع العناصر رسوم وجسيمات ضوئية، ولا توجد صور حقيقية. الكلمات تتشكّل من الجسيمات ثم تتحوّل إلى رموز، وتعود الرموز لتكوّن الكلمات.

| الملف | الوظيفة |
|---|---|
| `cues.js` | التوقيتات المشتركة بين الصورة والصوت: النبضات، والمؤثرات، والضربات، ولحظات الصمت |
| `index.html` | محرّك الجسيمات والمشاهد. افتحه في المتصفح لمعاينة الفيديو مع الصوت |
| `scripts/soundtrack.py` | يولّد الموسيقى السينمائية والمؤثرات، ويضع التعليق الصوتي في موضعه، وينتج `assets/soundtrack.wav` و`assets/soundtrack.m4a` |
| `scripts/render.js` | يصدّر الفيديو إلى `out/teaser-echo.mp4` |
| `assets/emblem.png` | شعار المدرسة الذي يظهر داخل الدائرة البيضاء |
| `assets/voice.mp3` | التعليق الصوتي: «مِنَ الصَّوتِ… إلى الصَّدى» |

## التصدير

```bash
python3 scripts/soundtrack.py
node scripts/render.js
```
